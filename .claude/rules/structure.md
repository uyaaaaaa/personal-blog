# 置き場とデータの流れ

- composable は reactive / lifecycle を使い、2箇所以上（テストを含む）で使うものだけ。純粋関数は `app/utils/`、1箇所だけならそのコンポーネント内
- モジュールスコープの可変値は、SSR でリクエスト間に共有されて壊れないものだけ
- route に依存する取得は、そのルートの `pages/` が呼ぶ。依存しない取得は、出すコンポーネントが自分で呼ぶ。`layouts/` から props で配らない
- 自作モジュールの auto-import を戻さない
- リロード・共有・戻るで残る状態は URL から導き、別の state に複製しない。URL が表せない値は 404
- 同じ値の正本を2箇所に作らない。分けざるを得ないなら同じ変更で両方直す
- `useScrollFrame` の読み取りは、他の読み取りの書き込み結果に依存しない
- 表示の出し分けは CSS で行い、`v-if` で消さない
- ビルド時刻が焼き付く値はクライアントで計算する
- 出し分け・分岐・ルーティングを触ったら `dist/` の HTML まで見る
- `components/ui/` は題材（記事・サイト構造・Markdown 記法・エラー状態）を知らない部品だけ（[ADR 03](../../docs/adr/03-ui-knows-no-domain.md)）
- `pages/` でルートにしないファイルは `-` 始まりにする
- 複数のルートファイルに跨る一覧は、本体を1つにまとめる
