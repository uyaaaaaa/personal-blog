# コミットのルール

**件名には「何を」と「どう変えたか」の両方を書く。**

| 書く | 書かない |
| :--- | :--- |
| `View Allの判定をその幅で実際に見えている件数に合わせる` | `View Allの判定を直す`（どう変えたかが無い） |
| `ページングの判定を utils の純粋関数に出してテストで守る` | `コンポーネントの実装を整理する`（何を・どう、の両方が無い） |

- ファイル名・件数・数値は書かない
- issue の文面を写さない
- 本文は任意で、書くのは「なぜ」だけ

## 1コミットの範囲

- ドキュメントの更新は実装と同じコミットに入れる
- 整形だけのコミットは分け、ハッシュを `.git-blame-ignore-revs` に足す
- 実測用の一時的な細工は含めない（→ `verify` スキル）
