# 検査を足すときのルール

- **検査を書く前に、その規約が成り立つ経路（設定・別の綴り・逆向きの走査）を実装と設定から全部数え、全部を同じ判定で見る。**
- **足した検査は、破る例が落ちることと通す例が通ることの両方をテストで固定する。**
- **判定を広げたら、広げた先で当たる対象でない綴り（比較・添字・初期値の違うプロパティ）を数え、落とさないことを確かめる。**
- **別のファイルが持つ綴りの一覧は、読み取りや正規表現で拾わず `import` して引く。**
- **フックは、読み取りや解析に失敗して判定できない入力を黙って通す。**
