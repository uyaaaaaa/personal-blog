# フェーズ3〜4: 書いて削る

記事の書き方（[SKILL.md](../SKILL.md)）のフェーズ3と4の手順。
取り決めシートが承認されたあと、本文を書き上げるまでが範囲。

## フェーズ3: 書く

### 共通の骨格

| ブロック | 役割 | 分量 |
| :--- | :--- | :--- |
| 入り口 | 読者が「自分の話だ」と気づく。事象・疑問・きっかけ | 1〜3文 |
| 本題 | メッセージそのもの。原因 / 仕組み / 手順 | 全体の6割以上 |
| 結論 | メッセージの1文を、読者が使える形で再掲 | 数文 |
| 参考 | 一次情報へのリンク | リンクのみ |

「入り口」で背景を語りすぎない。**本題に一番文字数が割かれていない記事は、構成を間違えている。**

### 型を選ぶ

シートで決めた型に沿う。混ぜない。

| 型 | 見出しの並び | 手本 |
| :--- | :--- | :--- |
| **トラブルシュート** | 前提・環境 → 発生した問題 → 原因 → 解決策 → 参考 | `react-native-reduce.md` |
| **疑問の深掘り** | 不思議に思ったこと → 調べてみた → 注意したい点 | `php-null.md` |
| **道具の紹介** | はじめに → 何ができるか → 使い方 → おわりに | `linux-fg-bg.md` |
| **作業ログ** | 背景と前提 → 工程ごとの見出し → ハマった点 → おわりに | `s3-to-rds.md` |
| **Tips集** | 見出し = Tips 1つ。並列 | `vim-command.md` |
| **書評** | どんな本か → 印象に残った点 → おすすめの読者 | `architecture-textbook.md` |

新しい型が必要になったらこの表に足す。

**Tips集型だけは1記事1メッセージの例外。** ただし道具は1つに固定する（vimならvimだけ）。
道具が混ざったら分割対象。この型では想定読者が「その道具を日常的に使っている人」に固定される。

### 素材の出しかた

- **バージョンと環境を書く。** 「PHP 7.0以降」「MySQL 8.0」のように、読者が自分に当てはまるか判断できる形で
- **一次情報にリンクする。** LLM や二次情報の要約を引くなら、公式ドキュメントへのリンクも必ず併記する（`mysql-index.md` の作法）
- **再現できるものは再現して書く。** 手元で動かせる最小例は、記憶の説明より短くて強い
- **裏が取れなかったことは「推測」と1文で明示するか、落とす**

### 書く順番

1. **見出しだけ並べる。** ここで「メッセージに奉仕していない見出し」を落とす
2. 本題から書く。入り口とおわりには最後に手を付ける

### 分量の目安

既存記事の実測は本文 1,200〜6,200字。

- 本文 **1,500〜4,000字**
- `##` 見出し **3〜6個**
- 1セクション **5〜15行**

**6,000字 / 200行を超えたら分割を検討する。** 作業ログ型だけは工程数ぶん超えてよい。

## フェーズ4: 削る

長い記事には、たいてい以下が混ざっている。書いたあとに上から順に探して消す。

| 削るもの | 具体例 | どうするか |
| :--- | :--- | :--- |
| 想定読者が知っていること | 前提技術の基礎解説 | 消す。シートで線は引けている |
| 前置きの自分語り | 「業務で〜という機会がありまして…」 | 1文に圧縮する |
| 調査過程の実況 | 試して外した案の逐一再現 | 結論に効いたものだけ残す |
| 教科書的な一般解説 | 用語の定義を一から説明する | 公式ドキュメントへのリンクで済ませる |
| 網羅的な例外リスト | 主筋に関係ない条件分岐 | 丸ごと落とす（ぼかさない） |
| コードの全文貼り | 設定ファイル全体 | 差分と要点だけ。10行超えたら疑う |
| 言い換えの段落 | 「つまり」で始まり前段と同義 | 片方を消す |
| まとめでの本文再説明 | おわりに で全部おさらいする | メッセージの1文だけ残す |

### 書き終わったら

- [ ] `description` フロントマターが、メッセージの1文を縮めたものになっている
- [ ] シートの「落とすもの」が本文に紛れ込んでいない
- [ ] **出せない情報が残っていない**（社内の固有名詞、実スキーマ、URL、顧客名）
- [ ] `npm run build` が通る（コードブロックの言語指定漏れはここで出る）
