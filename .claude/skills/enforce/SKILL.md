# 規約を検査に移す

**ここでは実装しない。** 探して issue にするところまで。実装は `assign` が持つ。

**検査を足すことと、移った規約の行を消すことで1つの変換。** 片方だけだと二重管理が残る（→ `docs/ARCHITECTURE.md`）。

**判定の結果を文書に残さない。** 出すのは issue だけ。除外リストも進捗表も作らない（→ [ADR 11](../../docs/adr/11-no-enforcement-inventory.md)）。

## 1. 集める

`.claude/rules/*.md` の太字の断定と、`docs/DESIGN_GUIDELINE.md` の「原則」「守る線」。1項目を1本として数える。

**「機械が落とせない」と書いてある項目こそ読む。** その断言は書いた時点の道具で下したもので、道具が増えれば失効する。失効したまま残ると、目視で受け続けることになる。

## 2. 置き場で落とす

判定に何が要るかで置き場を決める（→ `docs/ARCHITECTURE.md`）。決まらなければ落とす。

| 判定に要るもの | 置き場 |
| :--- | :--- |
| 整形 | Prettier |
| ファイル1つ | ESLint。`<style>` の中身は `eslint-rules/style-tokens.mjs` が postcss で読んでいる |
| 依存グラフ | dependency-cruiser |
| ファイルをまたぐ突き合わせ | `scripts/` の検査 |
| コミットの本文 | `.githooks/` |

**人の読みが要るものは落とす。** 「原則として書かない」「2箇所以上で使うものだけ」「同じ値の正本を2箇所に作らない」は、判定に文脈が要る。規約のまま置くのが正しい。

**ツールを増やさないと書けないものは落とす。** 今ある道具で書けるものだけ拾う（→ [ADR 12](../../docs/adr/12-style-block-token-lint.md) が Stylelint を退けた理由と同じ）。

## 3. 既に落ちるか試す

**その規約を破る最小の例を書いて `npm run lint` と `npm test` にかける。** どのツールが何を見ているかを設定から読み解かない。読み解くと、既に効いている検査をもう一度足す issue が出る（→ ADR 11 の対価）。試した細工はコミットに含めない（→ `.claude/rules/commit.md`）。

| 結果 | どうする |
| :--- | :--- |
| 落ちる | 検査は既にある。規約の行が残っていれば、それを消す issue にする |
| 落ちない | 変換の候補。次へ |

## 4. 違反を数える

**今の実装に何件あるかを数える。** ここを飛ばすと、入れた瞬間に赤くなる検査を issue にしてしまう。

- **0件。** 今の状態を固定するだけで、直す作業が無い。先に出す
- **1件以上。** 実装を直すか規約を緩めるかの判断が要る。件数と該当箇所を「現状」に書き、どちらに倒すかは書かない

## 5. 既に出したものを落とす

同じ規約の issue を、**open と closed の両方**から探す。

| 見つかったもの | どうする |
| :--- | :--- |
| open | 落とす |
| completed で閉じている | 検査は入っている。規約の行が残っていれば、それを消す issue にする |
| not planned で閉じている | 一度「移さない」と決めている。落とす |

**その規約自体を見直す issue が open なら落とす。** 覆るかもしれない規約を検査で固めると、結論次第で入れた検査を捨てることになる。変換の可否より先に見る。

**判定の記憶は issue が持つ。** 同じ規約を毎週蒸し返さないための状態を、文書に作らない。

## 6. 出す

**1回に最大2本。** 違反0件のものを先に。書き方は `create-issues` の型に従う。

完了条件は次の2つだけにする。どちらも外から判定できる。

- その規約を破った変更が `npm run lint` / `npm test` / フックのどれかで落ちる
- 移した規約の行が `.claude/rules/` か `docs/DESIGN_GUIDELINE.md` から消えている

**どのツールにどう書くかを完了条件に入れない。** 置き場の見当は「手がかり」に1行で添え、指示ではないと明記する。

## 7. 報告

出した issue の番号とタイトルだけ。**1本も出さなければ報告しない。** 週次の「なし」を残さない。
