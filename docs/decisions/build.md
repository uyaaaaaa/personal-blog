# ビルドと配信

## ローディングバー

- **`throttle` を効かせる。** プリレンダ済みページのように即座に終わる遷移でバーを出さないため。
- **ルート遷移にしか反応しない。** ページ内の再取得（`refresh()` など）では出ないので、進行は各コンポーネントが自前で示す（→ [ArticleFallback](./error.md)）。

## 404

- **存在しないパスは静的な `404.html` が 404 で返す。** プリレンダの `routes` に `/404.html` を明示的に含めている。

## プリレンダ

- **カテゴリページは `crawlLinks` に任せず `routes` に明示する。** リンクが1本も無いページは生成されず、`/category/*` は `_routes.json` の `exclude` で Worker にも回らないため、そのまま静的な404になる。生成対象を画面のマークアップから独立させる。
