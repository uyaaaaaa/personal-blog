# 記事一覧

## Hero

- **メタ行にはタグではなくカテゴリのチップを出す。** カテゴリの方が構造的な情報で、`PICKUP`・タグ・カテゴリ・日付の4つを並べるとSP幅で窮屈になる。棚が消えるのはその記事がヒーローにいるときなので、ここにカテゴリを出しておくとTOPだけを見た読者にも軸の存在が残る（→ [索引の判断](../adr/10-category-index-in-header.md)）。
- **カテゴリのチップをリンクにしない。** カード全体が1つのクリックターゲットなので、入れ子のリンクを作らない。

## ArticleShelf

- **棚に出すカードが0枚なら棚ごと出さない。** 見出しと `View All` だけが残った棚は、`View All` が何に対する "All" なのか伝わらず、「記事が無い」という誤ったシグナルになる。カテゴリへの導線が消えることは、[索引をヘッダーが持つ](../adr/10-category-index-in-header.md)ので問題にならない。
- **`scroll-padding-left` を左パディングと同じ値にする。** スナップ位置はパディングボックス基準で決まるため、これが無いと初期表示でコンテナのパディングが無視され、先頭カードだけが画面端に張り付いて見出しと揃わない。
- **呼び出し側は常に6件を渡し、`1024px〜` では5・6件目を CSS で落とす。** ビューポート幅で取得件数を変えると静的生成できない。DOM には2枚多く残る。
- **`View All` は棚に出ていない記事があるときだけ出し、見出し自体も同じリンクにする。** 全件が棚に出ているカテゴリでは `View All` が消えるため、見出しをリンクにしてカテゴリページへの導線が無くならないようにする。
- **「棚に出ていない記事があるか」はその幅で実際に見えている件数で判定する。** 渡した件数と総数だけを比べていた頃は、PC で CSS が落としているカードが「出ている」扱いになり、記事が5〜6件のカテゴリで数枚隠れたまま `View All` も出ず、全件への導線が消えていた。
- **幅による出し分けは JS のメディアクエリではなく CSS で行う。** カードを落としているのが CSS なので判定も揃える。静的生成の HTML が最初から正しくなり、ハイドレーション後の切り替わりも起きない。

## ArticleList

- **記事のグリッドは `ArticleList` に集約する。** `AllArticles` `TagArticles` `CategoryArticles` は `articles` を渡すだけで、`ArticleCard` へのマッピングは `ArticleList` が行う。TOP は棚（`ArticleShelf`）を使い、グリッドを使わない。

## ArticleCard

- **タイトルに `min-height: 2.6em` を持たせる。** 1行タイトルと2行タイトルが混在してもカードの高さが揃う。

## Pagination

- **ページ番号はパスで持つ。** 理由は[構造に関わる判断](../adr/01-page-number-in-path.md)。
- **1ページ目は `/page/1` を持たず、素のパスを正とする。** `/page/1` は404にする。
- **ページ番号は URL だけが持ち、`usePagination` が `route.params.page` から `computed` で導く。** SSR とクライアントの結果が一致するため、ハイドレーションの遅延も先頭へのスクロール処理も要らない（パスが変わるのでルーターが先頭へ戻す）。
- **受け付ける表記は `2` のような正の整数だけ。** `2.0` のような別表記や範囲外は404。`basePath` が剥がせる形と、ページ番号として認める形を一致させるため。
- **1ページ目と2ページ目以降は同じ画面なので、実体を1つのコンポーネントに置き、ルートファイルはそれを描画するだけにする。**

| 画面 | 実体 | ルートファイル |
| :--- | :--- | :--- |
| 全記事 | `article/AllArticles.vue` | `article/index.vue` / `article/page/[page].vue` |
| タグ絞り込み | `article/TagArticles.vue` | `tags/[tag]/index.vue` / `tags/[tag]/page/[page].vue` |
| カテゴリ絞り込み | `article/CategoryArticles.vue` | `category/[category]/index.vue` / `category/[category]/page/[page].vue` |

- **省略は先頭・末尾・現在の前後1ページだけを残す。** それ以外は `…` で畳む。
