# 記事詳細

## 記事ヘッダー（`[_slug].vue`）

- **説明文は空なら要素ごと出さない。** フロントマターの `description` は空文字を許すため、無条件に描画するとタイトルと区切り線の間に空の1行分の余白が残る。
- **日付・カテゴリ・タグを1行に詰めない。** 件数の増え方が異なるため、1行に並べるとタグの多い記事で SP 幅（375px 想定）を超え、ページ全体が横スクロールする。件数が可変なのはタグだけなので、タグを独立した行に出して折り返させ、本数によらず1行目のレイアウトが動かないようにする。
- **カテゴリバッジは `ml-auto` で右へ寄せる。** 日付が無い記事でも右端に留まる。

## Toc

- **h3 の項目は左ボーダーを持たない。** コネクタ線から外れた位置に2本目の縦線が出る。
- **`overflow-x: hidden` を明示し、項目に `break-words` を与える。** `overflow-y` だけを指定すると `overflow-x` も `auto` に計算される。識別子や URL を含む長い見出しも折り返す。
- **目次自身が内部スクロールし、サイドバー全体はスクロールさせない。** `Sidebar` の `toc` スロットに `min-h-0` を与えるのはこのため（目次側だけが縮み、下のウィジェットが押し出されない）。
- **着地位置のオフセットを持たない。** 見出し側の `scroll-margin-top` が決める（後述）。

## TocMobile

- **ドロップダウンは `absolute` のオーバーレイにし、記事を押し下げない。**
- **ページ内ジャンプ中は方向によらずバーを隠す。** 上方向へジャンプした際にバーが現れて、着地した見出しや脚注に被るのを防ぐ。`isVisible` が `isProgrammaticScroll` を直接見るため、目次・見出しのスクロール（`useScrollTo`）と脚注のフラグメント遷移（`beginProgrammaticScroll`）の両方で効く。
- **`sticky` を持つ外側の要素と、隠れるときに `translateY` がかかる内側の要素を分ける。** sticky 判定は外側の位置で行うため、隠れるアニメーション中も判定がぶれない。同じ要素に両方を持たせると、変換量を `getComputedStyle` で読み戻して打ち消す必要が出る（以前はそうしていた）。`pointer-events` だけは外側に置く（内側を退避させても外側の当たり判定が残るため）。
- **項目タップ時のオフセットを計算しない。** ジャンプ中はバーが隠れるため、バーの高さを加味する必要がない。
- **`overscroll-contain` を付ける。** 目次内のスクロールが端に達しても背後のページを動かさない。

## ScrollToTopButton

- **`1024px〜` では出さない。** 右サイドバーに常時見えている目次が同じ役割を担う。
- **表示条件は「ビューポート1画面分」と「ページ全体の1/3」の大きい方。** 短い記事で出過ぎず、長い記事で遅すぎない。
- **濃さはスクロール量に連動させ、CSS トランジションを持たせない。** 表示開始位置から `FADE_DISTANCE` かけて不透明度を上げ、同じ式で戻る。トランジションがあるとスクロールに追従しない。
- **不透明度が0の間は DOM から外す。** 見えないボタンにフォーカスを拾わせない。
- **クリックで `scrollToTop()` と `clearHash()` を続けて呼ぶ。** URL のハッシュを取り除きたいのはこのボタンだけなので、`scrollToTop()` 側にはハッシュ除去を持たせない。
- **`z-index` は `TocMobile` のドロップダウンとその背景より後ろ。**

## ページ内リンクの着地位置

- **固定ヘッダーとの重なりは、呼び出し側のオフセット計算ではなく、着地する要素側の `scroll-margin-top` で一元管理する。** CSS で持つことで、JS によるスクロール（目次・見出しクリック）、ブラウザ標準のフラグメント遷移（脚注）、URL ハッシュの直接オープンのすべてに同じ着地位置が効く。定義は `[_slug].vue` の非 scoped スタイルにあり、`.prose` の `--landing-offset` を見出しと脚注（参照・定義）で共有する。
- **値の内訳**: `〜1023px` はヘッダー 64 + 余白 24、`1024px〜` はヘッダー 64 + 余白 32。
