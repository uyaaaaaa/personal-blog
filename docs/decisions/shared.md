# 共有ロジック

## useScrollFrame

購読を1本にした理由と実測の範囲は[構造に関わる判断](../adr/04-single-scroll-subscription.md)。

- **`read` は他の `read` の書き込み結果に依存してはいけない。** 1つの rAF コールバックの中で全部を続けて呼ぶため、読み取りが終わるまで Vue の DOM 更新は流れない。`TocMobile` の sticky 判定が `translateY` のかからない外側の要素を見ているのは、この制約を満たすためでもある。

## useArticleCategories

- **記事が0件のカテゴリは落とす。** `/category/[category]` は0件で404になるため、辿れないリンクを呼び出し側に渡さない。

## useHoverPanel

- **ホバーでの開閉は `pointerType` が `mouse` のときだけ効かせる。** タッチ操作はタップのたびに互換マウスイベント（`mouseenter` → `click`）を続けて発火させるため、限定しないと1回目のタップで開いた直後にクリックのトグルが閉じてしまう。タッチ端末はクリックの経路だけで開閉する。
- **パネルはポインタが離れてから少し遅らせて閉じ、ルート要素の外側クリックでも閉じる。** 後者はホバーできない環境向け。マウスでホバーして開いたあとに click すると閉じるが、その経路を残すために許容する。
- **`Escape` はトリガーにフォーカスを戻す。** パネルの中の要素を隠したまま閉じると、フォーカスが `body` に落ちてタブ順の位置を失う。

## useIsDesktop

- **`matchMedia` の購読はモジュールスコープで1本だけ持つ。** 境界値は Tailwind の `lg` と同じ。
- **表示の出し分けは Tailwind の `lg:` のままにし、JS は購読を止めるだけ。** `v-if` を採らなかった理由は[構造に関わる判断](../adr/04-single-scroll-subscription.md)。

## useTocActive

- **ページ最下部では最後の見出しを強制的にアクティブにする。** 最後の見出しが短いと、上端を通過する前にページが尽きる。

## useScrollDirection

- **最初の1回は基準位置を控えるだけで方向を決めない。**
- **`scrollY` を0でクランプする。** iOS のラバーバンドで負値になる。
- **プログラムスクロール中は方向によらず `'down'` を返す。** ジャンプ中にモバイル目次バーを出さないため（→ TocMobile）。

## useScrollTo

- **オフセットを受け取らない。** 着地位置は `scroll-margin-top` が決める。
- **`scrollTo(id)` は `history.pushState` でジャンプせずに URL ハッシュを更新する。**
- **`clearHash()` は `history.replaceState`。** 履歴を増やさないため、戻る操作は記事の1つ前へ抜ける。
- **スクロールと履歴操作を別の関数に分けている。** ハッシュを消したいのが `ScrollToTopButton` だけのため。
- **`behavior: 'smooth'` は常に指定する。** `prefers-reduced-motion` を参照しない理由は[構造に関わる判断](../adr/02-no-prefers-reduced-motion.md)。

## useProgrammaticScroll

- **「いま起きているスクロールをプログラムが起こしたか」を `useScrollTo` から切り出している。** 「スクロールさせること」とは別の関心事。生産側は `useScrollTo` の各関数と、ブラウザ標準のフラグメント遷移（脚注）を乗せるために直接呼ぶ `[_slug].vue`。消費側は `useScrollDirection` と `TocMobile`。
- **スクロールイベントが 150ms 止まったら終了とみなす。** `scrollend` は Safari の対応が新しいため、デバウンスで代用。
- **共有 `ref` をモジュールスコープに置く。** クライアントの操作でしか変化せず、SSR では書き込まれないため、リクエスト間の状態汚染は起きない。

## formatRelativeDate

- **表記は GitHub に合わせる。** 直近30日は相対表記、それより古いものは月日の絶対表記。
- **`now` を引数で受け取る。** 静的生成でビルド時刻が焼き付くのを避けるため、呼び出し側が `onMounted` で `Date.now()` を渡す。`null` の間は年つきの絶対表記を返す。パネルもドロワーも初期状態は閉じているので、切り替わりは画面に出ない。
- **日単位で比較するため、時刻ではなくその日の0時同士を突き合わせる。**
- **記事の日付は UTC 基準で読み出し、「今日」だけローカル基準で読む。** フロントマターの `date` は時刻を持たない暦日で、`new Date()` はこれを UTC の0時として解釈する。読み出しをローカル基準にすると、UTC より西のタイムゾーンで日付ラベルも相対表記も1日前にずれる。一方で相対表記の基準になる「今日」は閲覧者のローカル暦日が期待値なので、記事側と今日側で基準を非対称にする。どちらも UTC 0時のタイムスタンプに正規化するため、差分は DST の影響を受けない。
- **テストが渡す「今日」は 12:00 UTC にする。** 基準日をローカル暦日で読むので、0時に近い時刻を基準にするとテストの結果が実行環境のタイムゾーンで変わる。UTC±12 の範囲ならどのタイムゾーンでも同じ暦日になる正午を基準にし、タイムゾーンの違いを確かめる分だけ `vi.stubEnv('TZ', ...)` で明示的に切り替える。`vitest.config.ts` で `pool: 'forks'` を明示しているのは、この書き換えを他のテストファイルに漏らさないため。既定の `threads` ではワーカーが `process.env` を共有する。
