# Design Guideline

新しい要素を作るときに引く、デザインの判断基準です。**値・構造・機能の一覧は持ちません**（実装が正）。
原則を覆したときは同じ変更でここを直します（[ADR](./DECISIONS.md) が持つのは公開 URL とディレクトリ全体の判断だけです）。アイコンの仕様は [ICON_GUIDELINE.md](./ICON_GUIDELINE.md) にあります。

---

## コンセプト

**Functional Minimalism for Experts.** 装飾を足さず、コードと情報を速く読ませることに全部寄せる。

迷ったら「読む速さが上がるか」で決める。上がらない変更は、綺麗になっても採らない。

---

## 原則

1. **区切りは線と余白で作る。** 面を塗って区切らない
2. **影は重なりを示すときだけ使う。** 常時影のついた要素を作らない
3. **色を持つのは `accent` の1色だけ。** 意味のある状態（リンク、アクティブ、ホバー）、その画面が選ばせるために出している数、見出しに立つ記号（`#`、エラーコード）に使う。装飾・今開いているものの総数・ナビゲーションの中の数には使わず、迷ったら `sub` に置く。状態を示す手段は色に限らず、線の濃さでも作る
4. **技術的な情報は等幅で書く。** 日付、タグ、ラベル、セクション見出し
5. **値は名前で書く。** 色もサイズも、トークンに名前があるものだけを使う。角括弧の任意値（`w-[264px]`）は書かない
6. **動きは短く、種類を増やさない。** 動きに待たされる時間を作らない。長さも緩急も、用途を足す前に既にあるもので足りないかを見る。現れるものは減速させ、消えるものは加速させる
7. **幅の段は `md` と `lg` の2つだけ。** 段を増やすと確かめる組み合わせが増える。SP と PC の2通りを見れば全部見たことになる状態を保つ
8. **明暗は反転させず、同じ名前に値を割り当て直す。** 部品は明暗を知らない。暗色では手前にある面ほど明るくし、影だけに頼らず重なりが読めるようにする

---

## 守る線

機械が見ていないものは、変更のたびに目で確かめる。

- **コントラスト比 4.5:1 以上。** アクセント色で塗った面の上の文字も含む
- **入力欄の境界は、接する背景に対し 3:1 以上。** 区切り線は情報を持たないので対象外
- **文字の大きさは利用者の設定に従う。** 文字と、文字に合わせて決まる幅は `rem` か `em` で書き、`px` で固定しない
- **利用者の設定を打ち消さない。** 動きを減らす設定では動かさず、配色は `color-scheme` で宣言し、強制カラーでも状態が見分けられる
- **操作できるものの当たり判定は 24×24px 以上。** 文中のリンクは除く
- **キーボードのフォーカス位置は常に見える。** 祖先の `overflow` で輪郭が切れる場合も、吸着したヘッダーに隠れる場合も含む
- **`diff` は行の面で見せる。** 原則 1 に対する唯一の意図的な例外。差分は「どの行が変わったか」を面で追う情報と位置づける

---

## 破ってよいとき

**理由が外部にあるものだけ。** リポジトリを読んでも辿り着けない事情があるときに限り、原則 1 と 5 を破ってよい。

| 破ってよいもの | 外部の事情 |
| :--- | :--- |
| コードの構文色 | Shiki のテーマが持つ。上書きすると構文色の情報源が2つに割れる |
| 記事本文の体裁 | `@tailwindcss/typography` が持つ。本文のサイズ・行送りと見出しの倍率だけ上書きし、色はトークンにつなぎ、残りは差分を整える |
| Callout の配色 | Obsidian のテーマ由来。執筆環境でそのまま書けることを優先する |
| ロゴマーク | 意匠として確定済み。紫は UI の `accent` と別物で、追従させない（→ [ICON_GUIDELINE.md](./ICON_GUIDELINE.md)） |

## 画面の思想

実装を読んでも意図が分からないものだけ。

- **本文の1行は和文 40 字前後。** 幅は字数で決め、画面が広くても行長を広げない。記事ページだけ右に目次を並べ、他は中央 1 カラム
- **TOP の見せ場は PICKUP の1本だけ。** 棚はカテゴリごとの直近を並べる索引で、全件はカテゴリページが持つ
- **同じ記事を1画面に2回出さない**
- **記法は Obsidian 互換を優先する。** 執筆環境でそのまま書けることを、記法の綺麗さより優先する
- **UI の文言は英語。** 記事本文は日本語。英語の UI は `lang` で英語と示し、日本語の読みで読み上げさせない
