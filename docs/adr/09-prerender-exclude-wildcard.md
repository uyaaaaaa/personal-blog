# プリレンダ済みパスの除外をワイルドカードで畳む

`_routes.json` の `exclude`（`nuxt.config.ts` の `nitro.cloudflare.pages.routes`）で、記事・タグ・カテゴリを `/article/*` `/tags/*` `/category/*` のワイルドカードにまとめる。

- **検討した案**: パスを個別に列挙する。`exclude` は1ルートあたり1件で数えられ、Cloudflare の上限は100件。記事が増えるほど列挙が伸び、上限に達すると除外そのものが効かなくなって全記事が Worker 送りになり、SSR が失敗する。
- **対価**: ワイルドカードの配下に将来 SSR したいパスを作れない。作る場合は除外の粒度を切り直す。
- **戻す条件**: Cloudflare の上限が撤廃されたとき、または SSR したいパスが記事の名前空間の中に必要になったとき。
