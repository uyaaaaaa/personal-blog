# ページ番号をクエリではなくパスで持つ

`/article/page/2` の形にし、1ページ目は `/page/1` を持たない。

- **検討した案**: クエリ（`?page=2`）。最初はこれで実装した。静的生成では2ページ目以降が生成されず、そこにしか載っていない記事へのリンクがどの HTML にも現れなかった（`tags` は任意項目なので、タグの無い記事は完全に孤立する）。パスにすると `crawlLinks` がページャのリンクを辿って2ページ目以降も生成し、リンクを辿るだけで全記事に到達できる。
- **対価**: 一覧の URL が増え、記事が増えるほどプリレンダするページも増える。ページ番号の表記（正の整数のみ）と `basePath` の剥がし方を一致させる必要がある。
- **戻す条件**: 一覧を静的生成以外（SSR / CSR）で配信するようになり、到達性がリンク以外の手段（サイトマップなど）で担保されたとき。
