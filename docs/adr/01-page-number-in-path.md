# ページ番号をクエリではなくパスで持つ

`/article/page/2` の形にし、1ページ目は `/page/1` を持たない。

- **検討した案**
  - **クエリ（`?page=2`）**: 最初はこれで実装した。静的生成は1つのパスに1つの HTML しか焼けないので、2ページ目以降の一覧はどの HTML にも現れず、JS が動くまで1ページ目が出る。
  - **パス（`/article/page/2`、採用）**: `crawlLinks` がページャのリンクを辿って、ページごとの HTML を生成する。記事そのものは collection から直接プリレンダするので、一覧の形は記事への到達に関わらない。
- **対価**: 一覧の URL が増え、記事が増えるほどプリレンダするページも増える。ページ番号の表記（正の整数のみ）と `basePath` の剥がし方を一致させる必要がある。
- **戻す条件**: 一覧を静的生成以外（SSR / CSR）で配信するようになったとき。
