# メニューの先読みをホバー / フォーカスまで遅らせる

ヘッダーメニューが持つ記事・タグ・一覧へのリンクは `prefetch-on="interaction"`。

- **検討した案**
  - **`NuxtLink` の既定（`visibility`）**: リンクが IntersectionObserver に映った時点でプリレンダ済みの `_payload.json` を取りに行く。記事の payload は本文の AST を含んで1件 10〜30KB あり、パネルやドロワーを開いた瞬間に15件分がまとめて落ちる。デスクトップのパネルは `visibility: hidden` で隠しているだけでレイアウト上は見えている扱いなので、操作しなくても全ページのロードで発生する。
  - **先読みを切る**: 踏んだときの遅延が丸ごと乗る。
  - **`interaction`（採用）**: 実際に踏むリンク1本だけで済み、ホバーからクリックまでの猶予で間に合う。
- **対価**: タッチ環境ではホバーが無いので、タップと同時に取りに行く（先読みの効果が薄い）。オブジェクト形式（`{ interaction: true }`）では `visibility` がグローバル既定値にフォールバックして無効化されないため、文字列形式で書くという書き方の制約が付く。
- **戻す条件**: 記事の payload が小さくなったとき（一覧のクエリと同様に `select` で AST を外せるようになる等）。
