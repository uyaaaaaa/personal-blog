# 整形は Prettier に任せ、ESLint には持たせない

`.prettierrc` を整形の単一の設定にし、`npm run lint` の先頭で `prettier --check .` を回す。対象はコードだけで、Markdown（表のセルを文字数で揃えるため、全角が混ざると等幅表示で桁がずれる）と `package-lock.json`（生成物）は `.prettierignore` で外す。

- **検討した案**
  - **Biome**: script は整形するが Vue の template を1行も触らない。このリポジトリの不揃いは属性の折り返しに偏っていて template 側にあるため、直したいところが直らない。
  - **ESLint Stylistic**: template も script も整形でき、新しいコマンドも要らない。ただし整形のルールを1本ずつ議論して足すことになり、「整形を議論しない」という導入の目的と噛み合わない。「ESLint はプリセットを取り込まずルールを1本ずつ足す」方針は、整形を ESLint の外に出すことで守る。
  - **Prettier（採用）**
- **対価**
  - **`semi: false`**: テンプレートのインラインハンドラの `;` も落とすため、`@click="a(); b()"` のような2文のハンドラは書けない（改行区切りの2文になり、Vue のテンプレートコンパイラが式として解釈できずビルドが落ちる）。関数に切り出して渡す。
  - **要素の中身の折り返し**: 折り返されると Vue の `whitespace: 'condense'` が改行とインデントを空白1つに畳むため、テキストの前後に空白が1つ増える。表示は変わらないが、生成物のバイト列は変わる。
  - **インライン要素の閉じタグ**: 空白が意味を持つインライン要素（`<time>` `<span>` 等）では折り返せないため、`>{{ x }}</time` の後に `>` だけの行を置く形になる。
  - **`package.json` がタブになる**: npm は `package.json` の字下げを `package-lock.json` にも使うため、次の `npm install` がロックファイル全体をタブで書き直す。一度きりで、以後は npm が同じ字下げを保つ。
- **戻す条件**: Vue の template を Prettier と同等に整形できる別の formatter が出て、上の対価のどれかが消えたとき。
