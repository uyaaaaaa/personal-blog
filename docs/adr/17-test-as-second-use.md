# テストを2回目の使用とみなして抽出する

判定ロジックは、呼び出し側が1つしか無くても、テストを書く時点で `app/utils/` の純粋関数に出す。「抽出は2回目の使用時に行う」の2回目を、テストが埋める。

- **検討した案**: 抽出せず、コンポーネントを `mountSuspended` でマウントして外から判定を確かめる。ページ番号の別表記（`/page/01`）や省略記号の出る境界のように、判定は入力の組み合わせで増えるため、1件ごとにマウントとレンダリングを挟むことになる。`usePagination` 側は `useRoute` のモックも要る。テストが Nuxt 環境を要求する点は[テストの土台は Nuxt を起こさない範囲に留める](./15-test-setup-without-nuxt.md)とぶつかり、コンポーネントの構造を変えるだけでテストが落ちる。
- **対価**: `app/utils/` が増え、判定がそれを使うコンポーネントから離れる。呼び出し側が1つのままの util ができるため、「2箇所以上で使うものだけ抽出する」を字面どおりには読めなくなる。
- **戻す条件**: 抽出先が1つのコンポーネントからしか呼ばれず、そのテストも消えたとき。呼び出し元に戻す。
