# カテゴリの索引をTOPの棚からヘッダーに移す

`/category/[category]` への導線をヘッダーの `Explore`（パネルとドロワーの `Categories`）が持ち、TOP の棚は「見せ場」に徹する。棚に出すカードが0枚なら棚ごと出さない。

- **検討した案**: (1) 棚の存在判定をヒーロー除外前の件数にする。導線は戻るが、記事1本のカテゴリでその1本がヒーローになると見出しと `View All` だけの空の棚が出る。`View All` が何に対する "All" なのか伝わらず、「記事が無い」という誤ったシグナルにもなる。(2) ヒーロー記事を棚から除外するのをやめる。仕様は最も単純になるが、ヒーローはほぼ常に最新カテゴリの記事なので、稀なケースの対策として1画面に同じカードが2回出る状態を常時抱えることになる。(3) ヒーローのカテゴリチップをリンクにする。棚が消える条件とヒーローにいる条件が1対1で対応するので過不足がないが、ヒーローはカード全体が1つのクリックターゲットなので入れ子のリンクになる。(4) 索引をヘッダーに移す（採用）。`Tags` には索引ページもヘッダー導線もあるのに `Category` にはどちらも無く、`/category/*` へのリンクが TOP の棚だけという非対称が、そもそも棚を消すと 404 になる原因だった。
- **対価**: TOP を見ただけではカテゴリの一覧が分からず、`Explore` を開く必要がある。カテゴリが少ないうちは `Categories` のカラムだけ縦に余白が空く。
- **戻す条件**: 全カテゴリの一覧ページを持つことにしたとき。または TOP にカテゴリを常時見せる別の導線ができたとき。
