- @apply の任意値 ease-[…] が緩急の検査を抜けた → 長さと同じく ease- の接頭辞を @apply で落とした
- longhand で長さだけ書いた規則が ease のまま通った → 同じ規則に timing-function が無ければ落とす規則単位の判定を足した
- animation の緩急の省略が通った → 省略の判定を transition と animation で共通にした
- トークンと同名の --ease-* の上書きや、別名の変数を timing-function に渡す経路で任意の緩急が通った → --ease-* の宣言を緩急として走査し、timing-function にはトークンの変数だけを許した
- 短縮形の後ろ・前の longhand で緩急が決まる規則を省略として誤って落とした → 同じ規則の中で緩急を決める宣言を前後両方向に見るようにした
- 減速・加速の意図をコメントに書いた → CSS の仕様に当たる部分だけ残し、意図はコミット本文へ移した
