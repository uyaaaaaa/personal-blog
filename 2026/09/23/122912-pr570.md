- 中身で名前の付かないロール（slider・textbox など）を中身ありで通していた → ロールを中身で付くものとラベルで付くものに分け、後者はラベルだけを数える
- import() の別名判定が loader 関数の変数にも当たった → defineAsyncComponent を代入した変数だけに絞る
- `{ default as X }` の import が別名判定を抜けた → imported が default の ImportSpecifier も同じ判定に掛ける
- `<component :is="'button'">` と `<component :is="CloseIcon">` が名前・飾りの判定から漏れた → :is を読み、分かるタグとして判定する
- 条件式の :disabled を disabled とみなす指摘 → 値の決まらない式は通す方針なので採らず、人に渡した
