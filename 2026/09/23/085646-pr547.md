- 閉じた後も件数が支援技術に残る → 読み上げ用の文を、一覧を出している間だけ持つようにした
- 0件で領域が消えても緑のまま通る → 0件でも領域が在ることをテストで固定した
- N件から0件への変化だけ無音 → 出し入れする要素から読み上げを外し、常設の領域1つに寄せた
- 共有スタブを広げて他のテストの前提が動く → main のスタブに戻し、複数形は utils のテストに任せた
- `[role="status"]` が案内も拾う → `.sr-only[role="status"]` で取るようにした
- 同じ文が読み上げと画面で二重に並ぶ → 画面の案内に `aria-hidden` を付け、読み上げは常設の領域だけにした
- 打って0件に落ちる側が緑のまま変えられる → その条件の状態領域と案内の文をテストに足した
