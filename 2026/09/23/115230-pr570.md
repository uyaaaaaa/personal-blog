- 飾りの判定が名前→ルートの一方向だけで、ルートを隠した Icon 以外の部品が中身として通った → ルートを隠したら名前を Icon で終わらせる逆向きの判定を足し、LogoMark を改名
- 空の label を名前として数えた / disabled を要素と値を見ずにフォーカス外とみなした（Codex）→ 中身のある label だけ、効く要素と false でない値だけ
- テキストだけのルートで要素の判定を呼んで落ちた（Codex）→ VElement のときだけ呼ぶ
- Icon を別名で import すると飾りの判定を外せた → import 名とファイル名の Icon の終わり方を揃える判定
- SVG の camelCase 要素を部品として数えた → SVG 名前空間では小文字始まりをネイティブと見る
- 複数ルート（v-if / v-else）の部品で隠れたルートの判定が抜ける → 打ち切りで未対応、PR コメントで人に渡した
