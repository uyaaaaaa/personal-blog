- 引用とヒアドキュメントの本文をコマンドとして読み、文書を書く Bash を deny していた
  → Bash の綴りの読みを `.claude/hooks/command.mjs` に出し、`git-guard` と同じトークン化を通す
- Stop の理由が粗く、コミットすると push しないまま通れた
  → `commit` と `push` を別の kind にし、PNG → コミット → push の順に1回ずつ出す
- `seen` がファイル名だけで、撮り直した PNG が開いた扱いのままだった
  → 更新時刻を足して `名前@mtime` で数える
- 0 バイトの PNG は Read が落ちるので、「開く」の案内では抜けられなかった
  → `empty` を別の理由にし、撮り直しとして出す
- 新しい判断（セッションの終わりで止める）の根拠に、範囲の違う ADR 18 を引いていた
  → ADR 19 を足し、入口と終わりで行を分ける
