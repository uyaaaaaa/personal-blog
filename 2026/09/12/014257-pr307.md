# PR #307 で受けた指摘

- **must 署名の綴りに触れた本文の行が消える**（`pr-guard.mjs`）
  4つの署名のうち1つだけ行頭の錨が無く、本文の途中の綴りに当たっていた。行頭の飾り（`_` `*` 絵文字）だけを跨ぐ形に揃えた。
  正規表現を1本だけ書き足すと、他と条件が揃っていないことに気付かない。

- **must 未 push のブランチで理由が git の fatal 3行になる**（`pr-guard.mjs`）
  失敗した git の出力を戻り値として返していたので、空の結果と区別できなかった。`git()` 自体を「失敗は null」に直した。
  同じ穴が `touched` と `head` にも開いていた。指摘された行ではなくヘルパを直す。

- **suggestion overlay と無関係な綴りで作成が deny になる**（`pr-guard.mjs`）
  probe から綴りを引くとき、ファイル全体を見ていたので `is-active` `verify` まで拾っていた。`OVERLAYS` の表だけを切り出す形にした。
  「一覧を持たず、正のあるファイルから引く」ときは、そのファイルのどこから引くかまで決める。

- **suggestion 番号に触れただけの呼び出しで見届けが済んだ扱いになる**（`pr-followup.mjs`）
  照合が「番号を含むか」だけだったので、`PR #N の CI を直す` の `create_session` でレビュー依頼が埋まった。手段ごとにその形（`review` と `/pull/N`、`#N`、`pullNumber` の一致）を見る形にした。
  「済ませたか」を数える検査は、数える対象の形まで見ないと素通りする。
