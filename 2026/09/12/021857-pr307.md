# PR #307 で受けた指摘（2巡目）

- **suggestion `*` 始まりの箇条書きなら、まだ本文の行が消える**（`pr-guard.mjs`）
  1巡目の指摘を直すとき、跨ぐ飾りに `*` まで入れた。`*` は Markdown の箇条書きの印でもあり、本文の行に当たる。
  錨を緩めて直すと、緩めた分だけ別の入力に当たる。跨ぐものは実際に付く飾りだけに絞る。

- **suggestion probe 側の改名だけで overlay の検査が黙って止まる**（`pr-guard.mjs`）
  ファイルを読んで綴りを取っていたので、`const OVERLAYS` の改名で表が見つからず、検査が false を返して素通りした。probe から export して import する形にした。
  「一覧を持たず、正のあるファイルから引く」ときは、読み取りではなく import で引く。壊れて分かる形でないと、古くなったことに気付けない。
