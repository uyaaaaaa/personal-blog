- git が失敗した回の終了コードが、記事だけの回と同じ値で黙って検査を飛ばしていた → catch して理由を1行出し、回す側の終了コードを定数で名付けた
- `--amend` は index が空になり、免除した件名のコミットが amend できなくなっていた → index が空なら `HEAD^` との差を見て、作り直す先のコミットで振り分ける
- 方針を覆したのに ADR が無かった（件名の形、commit で回すもの）→ ADR 21 を足し、索引と覆した箇所の両方から引いた
- 実測の細工を戻すときに、同じファイルへの本来の変更ごと `git checkout` で消していた（README）→ 消えた記述を入れ直し、効いている検査の列挙自体を落とした
- workflow のテストがグロブだけ見ており、`paths-ignore` を `paths` に書き換えても通っていた → キーを含む行ごと比べる
