## 検査の判定を手で並べた綴りに載せた

- **must: 受け手を見ない名前で正当な入力を落とした。** 挿入の綴りに `append` を入れたため、`URLSearchParams` / `FormData` / `Headers` の `append` が DOM の組み立てとして落ちた。衝突する名前だけを外し、衝突しない新しい綴り（`prepend` `before` `after` `replaceWith`）は残した
- **suggestion: 綴りの片側だけを数えた。** 文字列からの差し込みに `setHTMLUnsafe` だけを入れ、素の `setHTML` が抜けた。Unsafe 有無の両方を同じ判定に入れた

どちらも、名前の一覧を仕様から数えずに書いたことが原因。名前で見る検査は、その名前を持つ他の Web API と、同じ操作の別の綴りを先に数える。
