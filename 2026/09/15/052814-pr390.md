- must: scoped CSS のクラスが `a:hover` に勝ち、フッターのリンクだけホバーで色が変わらなかった。scoped の属性セレクタで特異度が上がることを踏まえていなかった。style ブロックごと畳んで Tailwind のユーティリティに移した
- imo: 群の見出しの体裁が `HeaderMenuColumn` の写しになっていた。周りが `tracking-marker` のユーティリティで書いている体裁を、自分だけ scoped CSS で書き起こしたのが原因。写しを消して既存の書き方に合わせた
- 両方とも「ui-change の『Tailwind のクラスを基本にし、複雑な状態やアニメーションだけ scoped CSS にする』を読み飛ばした」1つの原因から出ている
