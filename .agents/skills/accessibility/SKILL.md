# アクセシビリティ

目標は WCAG 2.2 AA。実装の型は [A11Y-PATTERNS.md](references/A11Y-PATTERNS.md)。
**全体の点検を頼まれたら、[WCAG.md](references/WCAG.md) の A と AA の表を1行ずつ当てる。** 下の「見る順」はこのブログで落ちやすい所で、全項目の代わりにはならない。当てはまらない行は、理由を1行添えて対象外にする。
実測の番号は [verify](../../../.claude/skills/verify/SKILL.md) の実測メニュー。手順書もそこから辿る。

## 見る順

1. **被せた UI（ダイアログ・ドロワー・検索）はキーボードで一周する。** 開く・閉じる・戻り先のフォーカスを verify の 7（`overlay-probe`）で測る。撮影では操作が送られない
2. **フォーカスが見えて、固定ヘッダーに隠れないか。** Tab で一巡し、着地した要素を verify の 6 で撮る
3. **幅と拡大で崩れないか。** 320px 幅と 200% 拡大で横スクロールと重なりが無いか、verify の 6 を 320px でも撮る。押せる要素は 24×24px 以上
4. **生成された HTML で名前と役割を見る。** `dist/` の該当要素に、アクセシブルな名前・見出しの階層・`lang` があるか（verify の 5）
5. **色は light / dark の両方で測る。** コントラストはテーマごとに変わる

## 直すとき

- ネイティブ要素を先に使う。ARIA は、ネイティブで表せないときだけ足す
- 実測は verify に従う。自動検査の点数は適合の証明にならないので、結果には観測した要素と操作を書く
