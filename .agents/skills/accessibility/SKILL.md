# アクセシビリティ

目標は WCAG 2.2 AA。基準の詳細は [WCAG.md](references/WCAG.md)、実装の型は [A11Y-PATTERNS.md](references/A11Y-PATTERNS.md) を、該当する項目に当たったときだけ読む。

## 見る順

1. **被せた UI（ダイアログ・ドロワー・検索）はキーボードで一周する。** 開く・閉じる・戻り先のフォーカスを `verify` の 7（`overlay-probe`）で測る。撮影では操作が送られない
2. **生成された HTML で名前と役割を見る。** `dist/` の該当要素に、アクセシブルな名前・見出しの階層・`lang` があるか（`verify` の 5）
3. **色は light / dark の両方で測る。** コントラストはテーマごとに変わる

## 直すとき

- ネイティブ要素を先に使う。ARIA は、ネイティブで表せないときだけ足す
- 実測は `verify` に従う。自動検査の点数は適合の証明にならないので、結果には観測した要素と操作を書く
